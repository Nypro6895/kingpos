Behavior
- Ordinary Forum reading tabs use authenticated browsing retention and a stable lifecycle across local History query changes. Header/tabs remain mounted while only the selected pane loads.
- Write/manage and sensitive URL flows retain their action-state reset and original server authorization.
- Topic lists use separate component-owned memory snapshots for feed/following/saved/mine and every applied filter. Fresh snapshots are reused for 30 seconds; stale data can display during a named read. New tabs never paint another tab's rows.
- No new persistent storage. Cache bounded to 12 list/filter keys and 200 retained rows per key; active pagination can continue beyond the retained window. Pagination preserves first-page freshness and deduplicates IDs.
- Successful writes invalidate list snapshots. Block/privacy changes clear them immediately. Request/epoch checks reject older results; failures clear payload/cache because current read errors cannot safely distinguish access withdrawal from service outages. Retry forces the current reader.
- A new server context is reconciled even if Activity interrupts its queued update. Existing draft/history behavior, scoped admission, server writes/moderation and Chat-only polling remain.
