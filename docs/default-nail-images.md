# Default nail-service images

Twenty AI-generated generic nail-service illustrations are served locally from `public/images/nail-defaults/`. They include French tips, burgundy, nude/gold, lavender, coral, emerald, cobalt, chrome, pearl, ombre, floral, geometric, glitter, marble, terracotta, manicure, pedicure, polish swatches, tools, and midnight stars.

Explore and profile covers select a stable pseudo-random image using the salon ID when a nail business has no cover. Real salon photos always take priority. Hair and massage businesses receive no nail fallback. The cover carries an `AI illustration` label and descriptive alternative text.

These assets are display defaults, not salon uploads, actual work, reviews, or gallery posts. They do not change business media stored in the database. Generation source paths are recorded in `artifacts/wisconsin-directory/nail-image-sources.json` for provenance.
