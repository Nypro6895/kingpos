Windows POS 0.7.0 connects directly to https://reylumi.com/pos/portable.

Download **KingPOS Portable-Setup-0.7.0.exe**, open it on Windows x64, and sign in
with your salon POS ID and passcode. No local web server is required.

This installer is unsigned; Windows may show an unknown-publisher warning.
Native updates are manual in this edition. Download future installers from
https://reylumi.com/download/windows.

Local test installations keep a separate data profile. Upload pending tickets
with the original local server before switching; local data is not automatically
migrated to the online server.
