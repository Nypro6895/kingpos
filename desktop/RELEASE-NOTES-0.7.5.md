# KingPOS Portable 0.7.5

Coordinated release with the post-97 hosted application and approved POS/Gift layout. The Gift entry appears once below Discount/Tip; staff and customer screens share the current Gift artwork and layout styling, preserving staff wallet controls and the existing sale/confirmation rules.

Adds only the closed-ticket-edit archive storage namespace required by the shared-ticket workflow. The native host, encrypted ticket vault, offline shell, pairing and user-controlled updater otherwise preserve the exact published 0.7.4 implementation. Hosted saved-ticket loading remains compatible with older hosts that lack this optional namespace. This release uses the existing Online channel, app identity, data profile and Reylumi download/update endpoints. No automatic install on exit, permission change, data migration or signing-channel change.
